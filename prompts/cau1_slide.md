# CÂU 1 — Slide giới thiệu sản phẩm + hình ảnh + lời thuyết trình audio (LÀM TAY)

## CÁCH DÙNG (đọc trước)
1. Mở **ChatGPT** (chatgpt.com) hoặc **Gemini** (gemini.google.com).
2. Đính kèm **ảnh/file đề thi** (nút +) → bấm "Copy prompt" ở web → dán vào ô chat → Enter.
3. AI sẽ trả về: (A) yêu cầu đề đã hiểu, (B) nội dung slide dạng dán vào Gamma, (C) lời thuyết trình từng slide, (D) các bước làm cụ thể theo công cụ đề yêu cầu.
4. Làm theo mục (D). Đường nhanh nhất mặc định:
   - **gamma.app** → Create new → **Paste in text** → dán mục (B) → chọn chủ đề đẹp → Generate (Gamma tự tạo ảnh AI).
   - Gamma: nút **⋯ → Export → PowerPoint (.pptx)**.
   - Mở file .pptx bằng PowerPoint → tab **Slide Show → Record** (Ghi lại) → đọc lời thuyết trình mục (C) cho từng slide → Stop → File Save.
     (Hoặc từng slide: **Insert → Audio → Record Audio**.)
   - Muốn giọng AI thay vì giọng mình: dán lời thuyết trình từng slide vào **ttsmaker.com** (chọn Vietnamese) → tải mp3 → PowerPoint **Insert → Audio → Audio on My PC** → tab Playback chọn **Start: Automatically**.
5. Nộp file .pptx (hoặc File → Export → Create a Video nếu đề yêu cầu video).

===== PROMPT (copy từ dòng dưới) =====
Bạn là trợ lý hướng dẫn thi thực hành môn "Chuẩn đầu ra Trí tuệ nhân tạo". Tôi đã đính kèm đề thi. Hãy CHỈ tập trung vào CÂU 1 (tạo slide giới thiệu sản phẩm có hình ảnh và lời thuyết trình bằng audio trên slide).

Làm lần lượt, trình bày rõ ràng bằng tiếng Việt:

(A) YÊU CẦU ĐỀ: tóm tắt ngắn các yêu cầu của câu 1 (sản phẩm, số slide, công cụ AI bắt buộc, định dạng nộp, ngôn ngữ). Nếu đề không nêu sản phẩm thì chọn một sản phẩm phổ biến, dễ trình bày; nếu không nêu số slide thì làm 7 slide.

(B) NỘI DUNG SLIDE ĐỂ DÁN VÀO GAMMA: đặt trong 1 khối code để tôi copy. Mỗi slide bắt đầu bằng "# Tiêu đề slide", sau đó 3–5 gạch đầu dòng ngắn (≤14 từ), các slide phân cách bằng dòng "---". Slide 1 là trang bìa (tên sản phẩm + slogan), slide cuối là lời cảm ơn. Nội dung nên có: vấn đề/nhu cầu, giới thiệu sản phẩm, tính năng nổi bật, lợi ích, giá/đối tượng khách hàng, lý do nên chọn.

(C) LỜI THUYẾT TRÌNH: cho từng slide, 45–80 từ, văn nói tự nhiên, để đọc thành audio. Đặt tất cả trong 1 khối code, ghi rõ "Slide 1:", "Slide 2:"...

(D) CÁC BƯỚC THỰC HIỆN: hướng dẫn click-by-click ngắn gọn để hoàn thành câu 1 bằng đúng công cụ đề yêu cầu. Nếu đề không bắt buộc công cụ, dùng: Gamma (dán nội dung B, tạo ảnh AI) → Export PowerPoint → PowerPoint ghi âm lời thuyết trình (Slide Show → Record) hoặc chèn file mp3 tạo từ ttsmaker.com và đặt Start: Automatically cho từng slide → lưu .pptx.

(E) PROMPT TẠO ẢNH: 1 prompt tiếng Anh cho mỗi slide (phong cách nhất quán, không có chữ trong ảnh) để dùng nếu cần tạo/đổi ảnh bằng ChatGPT hoặc Gemini.
